# نظام التدقيق الآلي (Streamlit)

يكتشف قاعدة بيانات (MySQL / PostgreSQL / SQLite)، يوصّفها، ويشغّل فحوصات تدقيق مكتوبة بـ YAML في `checks/`.

- **النسخة المنشورة:** وضع تجريبي على بيانات وهمية (`demo.db`)، بدون اتصال بقواعد خارجية.
- **محلياً:** ضع `DB_URL` في ملف `.env` (انظر `.env.example`) ليعمل على قاعدتك.

```
pip install -r requirements.txt
streamlit run app.py
```

## الأمان: مستخدم قراءة فقط (موصى به بشدة)

الأداة تحتاج القراءة فقط. أنشئ مستخدم `SELECT`-فقط بدل الاتصال بمستخدم إداري:

```
mysql -u root -p < setup_readonly_user.sql
```

بدّل كلمة المرور داخل الملف أولاً، ثم اجعل `DB_URL` في `.env` يستخدم `audit_ro`. هذا هو الحاجز الأمني
الحقيقي. الكود يفرض أيضاً وضع القراءة فقط على مستوى الجلسة (MySQL و PostgreSQL) كطبقة إضافية، لكنها
لا تُغني عن مستخدم القراءة فقط.

## ملاحظات إنتاجية

- **الأسرار:** `.env` مستثنى من Git؛ لا تضع فيه إلا محلياً.
- **الذكاء الاصطناعي:** الوكيل يُخرج `SELECT` فقط يمر على حارس القراءة فقط. ضع سقف إنفاق في لوحة
  Anthropic. قيم البيانات تُرسل للنموذج مع تقنيع الأعمدة الشخصية.
- **النشر العام:** النسخة العامة مقفلة على `demo.db` بلا مفتاح API؛ لا تنشر التطبيق على قاعدة حقيقية
  بدون إضافة تسجيل دخول أولاً.
